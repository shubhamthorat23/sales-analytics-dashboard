# Online Retail Sales Insights Dashboard

## 📊 Project Overview

This project analyzes e-commerce sales data to identify key business insights such as revenue trends, top-selling products, and country-wise performance.

## 🛠 Tools Used

* Power BI
* Excel / CSV Dataset

## 📈 Key Insights

* UK generates the highest revenue
* Few products contribute to majority of sales
* Sales peak during year-end season

## 💡 Recommendations

* Focus on top-performing products
* Expand in high-revenue countries
* Leverage seasonal demand for growth

## 📂 Files Included

* Power BI Dashboard (.pbix)
* Dataset
* Dashboard Screenshot

## 🚀 Outcome

Built a professional, client-ready dashboard demonstrating real-world data analytics skills.
